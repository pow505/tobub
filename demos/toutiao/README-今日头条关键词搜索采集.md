# 今日头条关键词搜索采集

## 用途
从今日头条首页搜索框发起关键词搜索，进入“资讯”结果页，按页面“下一页”连续翻页，达到指定数量或结果耗尽时停止。每条记录包含标题、简介、文章 URL、作者、评论数、发布时间文本和页码，保存到 Tobub 会话内容数据库。

首页搜索按钮会打开新的搜索标签页；Skill 通过 Tobub 的 `browser.pages()` 取得页面引用，再用带 `page` 的 Atom 继续操作。不会直接拼搜索 URL 作为入口。

## 参数
- `keyword`：必填，1–100 字符。
- `count`：1–100 的整数，默认 50。

## 结果与边界
评论数未在结果卡片展示时为 `null`；发布时间保留页面显示文本，不推断年份或时区。单次最多采集 100 条、最多遍历 50 页。如果页面停止前进或不足指定数量，结果状态为 `partial`，不会把部分结果报告为成功。

## 导入
通过 Tobub 的 Skill 导入流程导入同目录的 `.skill.json` 文件。导入预检已通过运行中的 Tobub Runtime 1.8.2。

- 重复 0、失败 0；Skill 输出状态 `ok`。
- 会话详情显示“内容 50”“新增 50”“共 50 条”。会话 ID：1445。
- Tobub Skill 编译检查有效；导入预检为 `installable`，平台可复用，无 Rule 依赖。
