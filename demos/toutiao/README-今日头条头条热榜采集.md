# 今日头条头条热榜采集

这是一个无自定义参数的 Tobub Skill。它从今日头条首页右侧“头条热榜”开始，读取当前批次的榜单名次、标题和链接，点击“换一换”并核对榜单内容变化；按稳定内容 ID 去重，收集到 50 条后停止。每条数据通过 `tobub.db.saveContent` 写入 Tobub 核心内容库，并保留批次、名次及榜单原文。

若热榜控件消失、连续批次没有进展、数据库写入失败或达到批次上限，技能会返回 partial/empty 状态和停止原因，不会把未收满的结果标为成功。

## 验证记录

- Tobub Runtime 1.8.2：静态检查通过，安装包检查通过。
- 可见浏览器 Run：`run_1792983942847_vd72`，Session `1448`。
- 结果：50 条已持久化，5 批，点击“换一换”4 次，50 个唯一内容 ID，名次覆盖 1–50，失败/重复均为 0。
- Tobub Studio 会话详情显示“数据 内容: 50 / 共 50 条”。
- 该目录中的关键词搜索采集包是另一项技能；本包不接收关键字或其他参数。
